# ИИ-агент для сайтов (KI-Chat-Assistent)

Чат-помощник для сайта клиента: отвечает посетителям по базе знаний бизнеса (на немецком, английском и других языках), принимает заявки (бронь, запись, предзаказ, обратный звонок) и присылает их владельцу в Telegram.

```
Сайт клиента ──(widget.js)──► ваш сервер (app.py) ──► Claude API
                                      │
                                      └──► заявка в Telegram владельцу
```

## Что внутри

| Файл | Что это |
|---|---|
| `app.py` | Сервер: принимает сообщения, спрашивает Claude, передаёт заявки в Telegram |
| `knowledge.md` | **База знаний бизнеса.** Для каждого клиента своя |
| `static/widget.js` | Окно чата. Вставляется на любой сайт одной строкой |
| `static/demo.html` | Демо-страница вымышленного кафе для показа клиентам |
| `../render.yaml` | Настройки для хостинга Render (регион Франкфурт) |
| `.env.example` | Список настроек |

Защита встроена: лимит сообщений с одного IP, дневной лимит (чтобы не «сжечь» бюджет), галочка согласия (DSGVO), предупреждение, что отвечает ИИ.

## Запуск — всё можно сделать с телефона

### 1. Ключ Claude API
1. Откройте **console.anthropic.com** и зарегистрируйтесь.
2. **Billing** → пополните баланс (оплата картой, оплачиваете то, что расходуете).
3. **API Keys** → **Create Key** → скопируйте ключ (`sk-ant-...`). Ключ показывается один раз, сохраните его.
4. Рекомендуется в **Limits** поставить месячный лимит расходов.

### 2. Telegram для заявок
1. В @BotFather создайте бота (`/newbot`) и возьмите токен.
2. Напишите своему новому боту любое сообщение (иначе он не сможет вам писать).
3. В @userinfobot узнайте свой ID. Это `TELEGRAM_CHAT_ID`.

### 3. Хостинг Render (бесплатный тариф для демо)
1. Откройте **render.com** → **Sign up with GitHub**.
2. **New** → **Blueprint** → выберите репозиторий `Telegram-bot`. Render найдёт `render.yaml`.
3. Render попросит заполнить: `ANTHROPIC_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
4. **Apply / Deploy**. Через 2–5 минут появится адрес вида `https://ki-chat-assistent.onrender.com`.
5. Откройте этот адрес: это демо-страница. Нажмите «Fragen? Chat» и задайте вопрос.

На бесплатном тарифе Render «засыпает» без посетителей, и первый ответ после паузы идёт около минуты. Для реального клиента переключите сервис на платный тариф (Starter).

### 4. Проверка
- `https://ВАШ-АДРЕС/health` должен показать `"ok": true` и `"telegram": true`.
- Напишите в чате: «Ich möchte für Samstag 10 Uhr einen Tisch für 4 reservieren», затем имя и телефон. Заявка должна прийти вам в Telegram.

## Новый клиент — пошагово

1. **Соберите информацию** (анкета): услуги или меню с ценами, часы работы, адрес, контакты, условия (бронь, доставка, отмена), частые вопросы, чего агент говорить не должен.
2. **Заполните `knowledge.md`** по образцу. Пишите фактами: агент отвечает **только** по этому файлу.
3. **Проверьте агента**: 20–30 вопросов, включая каверзные («есть скидки?», «вы человек?», вопросы не по теме).
4. **Вставьте виджет** на сайт клиента перед `</body>`:
   ```html
   <script src="https://ВАШ-АДРЕС/widget.js"
     data-name="Name des Betriebs"
     data-color="#2c6a4c"
     data-greeting="Hallo! Wie kann ich Ihnen helfen?"
     data-privacy="https://seite-des-kunden.de/datenschutz"
     defer></script>
   ```
   - **WordPress:** плагин для вставки кода (например, WPCode) → Footer.
   - **Wix:** Settings → Custom Code → Body end.
   - **Squarespace:** Settings → Code Injection → Footer.
   - **Jimdo / IONOS:** блок «HTML/Widget».
5. В `ALLOWED_ORIGINS` укажите домен клиента, чтобы виджет нельзя было вставить на чужой сайт.

Одному клиенту — один сервер (свой `knowledge.md`, свой Telegram-чат). Проще всего: отдельная копия репозитория и отдельный сервис на Render на каждого клиента.

## Модель и стоимость
- По умолчанию `MODEL=claude-opus-5-5` с `EFFORT=low`: самые качественные ответы.
- `MODEL=claude-haiku-5-5` в десятки раз дешевле, для простых FAQ обычно хватает. Проверьте качество на вопросах клиента перед переключением.
- Расход видно в console.anthropic.com → Usage. Закладывайте его в абонентскую плату клиента.

## DSGVO / право ЕС — чек-лист (не юридическая консультация)
- [ ] В **Datenschutzerklärung** клиента: чат обрабатывает сообщения через Anthropic (Claude) и хостинг (Render); цель — ответ на запрос; основание — согласие (Art. 6 Abs. 1 lit. a DSGVO).
- [ ] **AVV / DPA:** у Anthropic есть Data Processing Addendum для коммерческих клиентов, его нужно принять в консоли. У Render — свой DPA.
- [ ] Галочка согласия в виджете включена (есть по умолчанию), ссылка `data-privacy` ведёт на Datenschutz клиента.
- [ ] Посетителю видно, что он говорит с ИИ (надпись «KI-Assistent» есть по умолчанию; требование прозрачности EU AI Act).
- [ ] Заявки с персональными данными хранятся только в Telegram владельца. Договоритесь с клиентом, кто и как долго их хранит.
- [ ] Для собственного бизнеса в Германии: Gewerbeanmeldung, счета (Rechnungen), договор с клиентом.

Для крупных клиентов лучше проверить формулировки у юриста.

## Локальный запуск (для разработчика)
```bash
cd ai-agent
pip install -r requirements.txt
cp .env.example .env   # и впишите ключ
uvicorn app:app --reload
# откройте http://127.0.0.1:8000
```
