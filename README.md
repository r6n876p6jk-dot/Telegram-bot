# Telegram-бот магазин ⭐💳

Бот с каталогом товаров и оплатой прямо в Telegram:

- **⭐ Telegram Stars** — для цифровых товаров (файлы, ссылки, доступ в канал, подписки);
- **💳 Банковская карта** — для физических товаров и услуг (через платёжного провайдера, например ЮKassa).

После оплаты бот сам выдаёт товар покупателю и присылает вам уведомление о продаже.

## Возможности

| Команда | Кто | Что делает |
|---|---|---|
| `/start`, `/shop` | все | Каталог товаров с кнопками «Купить» |
| `/free` | все | Бесплатный урок курса |
| `/course` | все | Список уроков (платные открываются после покупки) |
| `/mypurchases` | все | История покупок |
| `/paysupport` | все | Помощь с оплатой (обязательна по правилам Telegram) |
| `/terms` | все | Условия покупки |
| `/sales` | админ | Статистика продаж |
| `/refund <user_id> <charge_id>` | админ | Вернуть Stars покупателю (`charge_id` приходит в уведомлении о продаже) |

Все покупки сохраняются в базу `shop.db` (SQLite).

## Быстрый старт

1. **Получите токен бота.** В [@BotFather](https://t.me/BotFather): `/newbot` (или `/mybots` → ваш бот → **API Token**).
   ⚠️ Никогда не вставляйте токен в код и не загружайте его в GitHub.
2. **Узнайте свой Telegram ID** через [@userinfobot](https://t.me/userinfobot). Он нужен для уведомлений о продажах.
3. **Установите Python 3.9+** и зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. **Создайте файл `.env`** по образцу `.env.example`:
   ```
   BOT_TOKEN=123456789:ваш_токен
   ADMIN_ID=ваш_id
   PROVIDER_TOKEN=
   ```
5. **Запустите:**
   ```bash
   python bot.py
   ```

Оплата за Stars работает сразу, ничего подключать не нужно.

## Курс внутри бота

Уроки лежат в `files/lessons.json`:

```json
[{"title": "Урок 1. ...", "free": true, "text": "Текст урока с <b>HTML</b>"}]
```

- `"free": true` — урок доступен всем (бесплатный урок-приманка);
- остальные уроки открываются после покупки товара, у которого в `products.json` стоит `"course": true`;
- в тексте можно использовать теги Telegram: `<b>`, `<i>`, `<code>`, `<pre>`, `<blockquote>`, `<a href="...">`;
- админ (`ADMIN_ID`) видит все уроки без покупки, чтобы удобно было проверять.

Папка `files/` не загружается в GitHub (см. `.gitignore`), чтобы платный курс нельзя было скачать бесплатно. Если репозиторий **приватный**, можно убрать `files/` из `.gitignore` и хранить курс в репозитории. Тогда хостинг получит его вместе с кодом.

## Оплата картой

1. В @BotFather: `/mybots` → ваш бот → **Payments** → выберите провайдера (например, ЮKassa).
2. Сначала возьмите **тестовый** токен (Test) и проверьте покупку тестовой картой провайдера.
3. Вставьте токен в `.env` как `PROVIDER_TOKEN=...` и перезапустите бота.
4. Когда всё работает, подключите **боевой** токен (Live). Для этого у провайдера обычно нужен статус самозанятого, ИП или юрлица.

Если `PROVIDER_TOKEN` пустой, товары за карту в каталоге просто не показываются.

> Для работы в России ЮKassa может требовать передачу данных для чека (54-ФЗ). Если провайдер попросит, это добавляется параметром `provider_data` в `send_invoice`.

## Как менять товары

Все товары лежат в `products.json`:

```json
{
  "id": "course_bot",
  "title": "Курс «Telegram-бот с оплатой»",
  "description": "Пошаговый курс в PDF",
  "type": "digital",
  "price_stars": 200,
  "delivery": "Ваша ссылка: https://...",
  "file": "files/course.pdf"
}
```

- `id` — уникальное имя латиницей;
- `type` — `digital` (оплата Stars, поле `price_stars`) или `physical` (оплата картой, поле `price_rub` в рублях);
- `delivery` — сообщение, которое покупатель получит сразу после оплаты (ссылка, код, инструкция);
- `file` — *необязательно*: путь к файлу, который бот отправит после оплаты;
- `need_address` — *для `physical`, необязательно*: `false`, если это услуга и адрес доставки не нужен.

Почему цифровое только за Stars: по правилам Telegram цифровые товары и услуги в ботах продаются только за Telegram Stars.

В текстах товаров не используйте символы `<` и `>`, потому что бот отправляет сообщения в HTML-разметке.

## Где держать бота 24/7

Бот должен работать постоянно. Варианты:
- VPS (любой недорогой сервер), запуск через `systemd` или `screen`;
- PaaS-хостинги: Railway, Render, Fly.io и т.п. Добавьте переменные из `.env` в настройки хостинга.

## Вывод заработанных Stars

Stars копятся на балансе бота. Их можно вывести через [Fragment](https://fragment.com) или потратить на рекламу в Telegram: @BotFather → ваш бот → **Balance**.
